<シーン>
[タイトル]→[接続画面]→[ゲーム]→[リザルト] 以後、繰り返し。
接続画面の次に、チュートリアルを入れる予定です。

接続画面では、ルームのような形で、任意のボタンを押すと
ゲームに参加できるようになっています。
