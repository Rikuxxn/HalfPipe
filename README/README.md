<シーン>
[タイトル]→[接続画面]→[ゲーム]→[リザルト] 以後、繰り返し。
接続画面の次に、チュートリアルを入れる予定です。

接続画面では、ルームのような形で、任意のボタンを押すと
ゲームに参加できるようになっています。
※現段階ではサーバーを立ててないので繋がりません。


<基本操作>
F11でフルスクリーン

*** キーボード ***
・決定 		[enter]
・エイム 	[W,A,S,D]
・投擲 		[F]
・ポーズ 	[P]
・溜め		[スペース長押し]
・ジャンプ	[スペース長押し→リリース] ※ジャンプタイミングが来たら

*** ジョイパッド ***

・エイム 	[左スティック]
・投擲 		[右トリガー]
・ポーズ 	[START]
・溜め		[A長押し]
・ジャンプ	[A長押し→リリース] ※ジャンプタイミングが来たら
